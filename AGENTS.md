payouts-core is an OCaml (OxCaml) library for batches of outgoing payments. Build from
the workspace root with
`DUNE_BUILD_DIR=_build-payouts-core opam exec --switch 5.2.0+ox -- dune build --root .. @payouts-core/all`.
See `../oxcaml-claude-skills/AGENTS.md` for the workspace-wide guide.
